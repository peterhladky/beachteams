# Smoke-test idea (use this to try the whole pipeline once)

Create a new issue from the **Idea** form and paste:

Title: About screen
Idea: The app should have an "About" screen that shows the app name and the app version, so friends can tell me which version they run when they report a problem. No login needed, no data stored, no new dependencies.
Who benefits: every member and me as maintainer.

Expected: the Requirements Engineer classifies it as risk:low, asks at most a couple of
questions (e.g. where the screen is reached from), you approve (G1), the Test Designer writes
acceptance tests, the Developer implements, the Reviewers comment, you tick the checklist and merge.
